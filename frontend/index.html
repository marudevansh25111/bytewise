Using Bytewise safely

A few things worth knowing before you rely on an answer.

  • AI can be wrong. Answers may contain mistakes, outdated information or made-up details. Verify important facts against official documentation.
  • Test code before using it. Review and run generated code in a safe environment, especially anything that touches files, databases or security.
  • Never share secrets. Don't type passwords, API keys, tokens, card numbers or other personal data into the chat.
  • Privacy. Your chats are saved only in this browser. Your questions are sent to the server and to an AI provider so an answer can be generated.
  • Tech topics only. Bytewise is built for computer science and software questions.
